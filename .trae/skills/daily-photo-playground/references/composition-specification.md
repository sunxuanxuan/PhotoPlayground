# 日常照片情绪作品页：构成规范

在规划版式、编写生成提示词或判断结果是否偏离时读取本文件。

## 核心公式

```text
摄影素材 → 情绪主语 → 主主体切出 → 高饱和色场 → 几何叙事 → 小型照片证据 → 编辑排版
```

借用 ZINE 的空间纪律、信息密度和版式节奏，不要复制仿旧纸张、复古滤镜或随机 scrapbook 纹理。

## 页面比例

以 3:4 竖版为基准：

- 外部页面：暖白或奶油色，承担主要低信息区与边缘排版。
- 内部版心：以页面中轴建立稳定关系，并跟随内容选比例：竖向主体、树干、建筑或上升动作可用页宽 22–34%、页高 42–58%；横向动作、光影或器物关系可用页宽 34–46%、页高 30–44%；紧凑肖像可介于两者之间。允许克制偏移。
- 页面低信息区：约占 72–84%，必须包含一块完整、连续、无装饰的区域。
- 内部版心呼吸区：约占版心的 35–45%。
- 核心主体：集中在一个主要区域，不要平均铺满整张页面。
- 主体切出：通常占内部版心约 38–58%，必须被放大、错位、截断或从一至两处破开版心边界；人物与纵向环境可更高，横向关系可更宽，但不能吞没外部静区。
- 原照片窗口：默认 1 个，约占页面宽度的 10–15%。
- 外框文字：约占页面 1–2%；全部文字总面积控制在 1.5–3%。
- 中央文字组：约占页面 1.5–3%，由微型主词/手写词、副标题和 1–2 个标签或短注释组成；它是主构图的装饰节拍，不是四角装饰，也不能成为最大视觉面。
- 几何装饰：2–4 个从原图提取的形状，至少一个承担主体穿破、遮挡或叠压的结构关系，其余延长动作或连接照片窗口。
- 点线构成：最多 2 组点线关系；每组由 1 条方向线和 1–3 个节奏点组成，不得平均撒在四周。

比例是控制信息密度的范围，不要求像工程图一样相加为 100%；如果页面显得拥挤，优先扩大暖白外页和静区。

## 留白硬门禁

- 生成顺序必须是：暖白外部页面 → 连续静区 → 内部版心 → 主体与照片窗口 → 文字与点线。
- 暖白外部页面与低信息区必须维持约 72–84%，并至少保留一块完全无文字、无点线、无几何、无照片窗口的连续静区。
- 内部版心必须响应照片动势：竖向元素用窄高版心，横向关系用较宽版心，紧凑肖像用中间比例；主体局部越界不等于允许色场、写实背景或信息密度侵占外页。
- 所有非留白元素可组成有明确方向的内容簇，不使用固定宽高包络；不得平均撒开，并必须保留至少约 30% 页面面积的完整无标记静区。
- 若暖白低信息区少于约 72%、版心与主体动作没有方向关系、静区被切碎，或缩略图第一眼读到满幅色块，结果直接作废并重新生成。
- 修正失败结果时，先调整版心比例与主构图；不要只缩小所有元素、删除小字或散点来伪造留白。

## 四层重构结构

内部版心必须按以下顺序建立，而不是把原图缩进一个矩形框：

1. 纯色色场：替代大部分真实背景，负责情绪和空间。
2. 主体切出：从原图选一个主主体或主体关系，放大、抠出、错位或截断；它是视觉主角。
3. 几何叙事：将 2–4 个原图符号、方向或重复节奏放大为纯色形状；至少一个与主体形成穿破、遮挡或叠压，其余承担延伸或方向关系。
4. 原照片窗口：一个小型完整窗口，作为记忆证据，不承担主视觉。

若内部版心仍能完整看到房间、桌面、椅子、风景或整组静物，说明第一层解构没有完成。

## 三段式空间

每张图都要明确：

1. 主区：内部版心中的主体与主要色场。
2. 静区：连续留白或低信息色场，不放散点、照片窗口和长文字。
3. 收尾区：一个小型照片窗口、少量几何或一组边缘文字，用于结束视线。

不要把三个区域平均切割。允许主区偏下、偏侧或越出版心边缘，但静区必须保持完整。

## 主体切出与海报化

- 主体不是“被保留的物件”，而是从原场景中主动提取出来的海报主角。
- 先决定主主体，再删除不支持情绪的环境；不要把整张原图放入版心后再添加装饰。
- 主体允许保留局部摄影细节，但整体优先呈现色块、轮廓、白边、硬切边、错位和局部放大。
- 让主体与纯色几何发生轻微叠压或越界，制造动作和视觉张力；不要让叠加关系压满页面。
- 对静物照片，优先选一组关系作为主主体，例如“兰花向上生长 + 茶壶停驻”，不要同时平均展示所有器物。

## 原照片窗口

- 只使用一个连贯画面，优先保留主体、动作和关键物件之间的关系。
- 默认缩小到页面宽度的 10–15%，但不要碎裁；窗口必须让人看得出它来自真实日常摄影。
- 原照片窗口必须与内部版心相邻，可轻微叠压版心边缘，但不能游离成第二个视觉中心。
- 使用薄边框、轻微错位或克制阴影建立层级。
- 不要使用撕纸边、胶带、重复照片条、宝丽来堆叠或多张微型裁片。

## 外框衬线体排版

把文字作为编辑信息，不要作为第二张海报：

- 默认只选 2–3 处：左上系列标签、右上情绪短语、左下观察词或单侧竖排边注。
- 使用衬线体、小型大写或细字重、宽字距；颜色使用深炭、深绿或与版心呼应的低明度色。
- 细规则线最多 1–2 条，用于建立对齐关系。
- 用户没有提供文案时，只生成与照片可见内容和情绪有关的中性短语。禁止虚构日期、地点、品牌、作者、期刊号、Logo 和水印。

## 中央文字排版

参考三张示例中的“主词—照片—解释”关系，把文字放进主构图内部：

- 中小型主标题/手写词位于主体或照片窗口的上方、下方或侧边，作为中央语义锚点；不要默认放在四角，也不要做成占据上半页的大号英文展示字。
- 小副标题紧邻主标题或照片窗口，用来解释情绪、动作或概念；保持 1–2 行短句。
- 标签/短注释可贴近照片窗口边缘、几何色块或主体局部，用小型大写、短色块标签或窄体字形成信息节点。
- 文字可以与主体或色场形成对齐、上下呼应、轻微穿插和错位，但不可遮挡主体关键识别锚点。
- 主标题、副标题、标签必须有明显字号、字重或字体差异；不要让所有文字同样小、同样轻。
- 中央文字总面积约占页面 1.5–3%，主标题宽度不超过页面约 14%；若文字只出现在页边，或大号英文先于主体被读到，视为主构图没有完成。
- 页边衬线小字、页码和竖排边注仍可保留，但降级为辅助层。

## 点线面构成

把外围留白设计成有秩序的低密度构成场，而不是空白画布：

- **面**：内部色场、主体切出、几何色块是主重量；外围不再增加大面积色面。
- **线**：用 1 条主规则线或轨迹线建立方向，可加 1 条明显更短的辅助线。主线可以指向主体、连接边注与版心，或回应原图中的枝条、栏杆、桌边、弧线。
- **点**：用 1–3 个小圆、短椭圆、花心色点、页码点或小色块制造停顿。点应来自原图符号或版式信息，不做随机星点和均匀撒点。
- **字**：2–3 处短文字信息形成语义节拍；手写主句可视为一个点，竖排边注与规则线组合可视为一条线。文字不要与主体争夺面积。
- **关系**：点、线至少要与主体、照片窗口、几何或文字中的一项发生指向、对齐、呼应或收尾关系；没有关系的装饰删除。
- **静区**：外围至少保留一块连续空白，不放文字、点、线和照片窗口，让构成有“停顿”。

## 纯色几何

把可见物件转译为形状，而不是导入新的装饰库：

- 栏杆、枝条、地平线 → 横条、折线或角形。
- 花心、果实、灯点 → 小圆、椭圆或短色块。
- 枝条、路径、波纹 → 一条弧线或断裂轨迹。
- 窗户、门、画框 → 矩形缺口或色块框。

保持形状不透明、无纹理、边缘清晰。形状之间和形状与主体之间都要保留空间，不要用几何填满暖白外页。

## 留白复核

- 暖白外页是否占主要面积，达到约 72–84%，并保留完整静区？
- 内部版心是否依照内容选择窄高、较宽或紧凑比例，并让内容簇保持清楚方向、避免平均散开？
- 主体、照片窗口、几何之间是否有呼吸距离？
- 如果缩略图显得拥挤，先调整版心比例与主体越界关系，再考虑减少文字或几何。
- 点线是否有主次：一条主方向线、少量节奏点、克制微型文字，而不是线框、散点和四边装饰？
- 点线是否把视线引回主体或收尾区？如果不能，优先删除而不是补更多元素。
- 中央文字是否和主体/照片窗口形成清楚的上下、左右或对齐关系？如果文字都退到四角，说明排版层级缺失。

## 场景转译示例

### 花朵摄影

删除完整花田，提取“紫色花群、枝条游走、花心重复”。让背景成为紫色空气场，用奶白花瓣与紫色几何花心重构主体；只在外框放少量衬线体观察词。

### 荷叶摄影

删除水面、荷梗和所有叶片，提取“层层叠放、漂浮、圆形叶片”。用少数扁平不规则叶片和统一绿色场表达关系；保留一个小型完整水面照片窗口。

### 海边摄影

删除完整风景，提取“树枝框住水面、远处长椅、短暂停留”。把海面变成内部色场，树枝变成粗线，橙色长椅变成信号色；外框排版保持安静。

### 游乐场人物

保留人物倒挂姿态、红鞋、蓝衣与绿色栏杆关系。让人物成为内部版心主角，只保留一个连贯小照片窗口；把栏杆转成绿色横条和黄色角形，不要生成纸片或多张动作碎图。

## 偏离判定

出现以下任一情况时重新生成或局部编辑：

- 原照片整张保留，只叠加滤镜、文字和装饰。
- 内部版心仍是完整写实场景，只在边缘添加色块、圆点和文字。
- 没有放大的主主体切出，版心第一眼仍读到桌面、房间或风景。
- 暖白外页少于约 72%，完整静区消失，版心与主体动作无关，元素平均散开切碎留白，或版心、主体、照片窗口互相挤压。
- 留白被散点、小字、贴纸或多个照片窗口切碎。
- 使用多张碎裁照片、胶带、撕纸、网点或仿旧纹理。
- 大标题、商业口号或外框文字抢过主体。
- 文字全部缩在四角，中央主构图只有图像和色块，没有“主词—副标题—标签”的编辑层级。
- 出现占据上半页的大号英文标题，文字比主体更抢眼，或中央文字总面积超过约 8%。
- 凭空出现日期、品牌、作者、Logo 或水印。
- 默认使用低饱和棕褐色、灰阶、3D、赛博朋克、卡通贴纸。
- 几何与原照片没有形态或情绪关系，只是随机三角形和圆点。
- 外围留白只有零散文字，没有清晰的方向线、节奏点和对齐关系；或点线平均铺满四周，导致静区消失。
